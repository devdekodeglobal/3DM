Database Schema & Password Storage Rules (Cloudflare D1)
Table Name Primary & Foreign Keys Columns Authentication & Security Rules
users id (TEXT PK) email, password_hash, name, avatar_url, google_id, email_verified, created_at, updated_at Google OAuth Users: password_hash is NULL (Password handled 100% by Google). google_id stores Google OAuth sub ID.
Email Users: google_id is NULL. password_hash is PBKDF2 with SHA-256 (100,000 iterations + salt) via Web Crypto API.
sessions id (TEXT PK)
user_id (FK → users.id)		 expires_at, created_at Server-side HTTP-Only, SameSite=Lax, Secure session cookie token (128-bit hex, 30-day lifespan). Indexed by user_id.
projects id (TEXT PK)
user_id (FK → users.id)		 name, description, created_at, updated_at Folders categorizing user interior designs. Indexed by user_id.
designs id (TEXT PK)
user_id (FK → users.id)
project_id (FK → projects.id)		 name, config (JSON), elements (JSON), created_at, updated_at Stores 2D wall dimensions, room config JSON, and 3D furniture/appliance fixture elements. Indexed by user_id & project_id.
otp_codes id (TEXT PK) email, code, type, expires_at, used, created_at 6-digit one-time passcodes for email verification (verify_email) and password resets (reset_password). Indexed by (email, type).
security_limits & rate_limits key / id (TEXT PK) count / hits, reset_at (INTEGER) IP-based rate limiting & DDoS protection across Cloudflare Worker auth endpoints. Indexed by reset_at.
oauth_challenges id (TEXT PK) verifier, expires_at (INTEGER) Temporary OAuth 2.0 PKCE state & code verifiers for secure Google authentication flows. Indexed by expires_at.
